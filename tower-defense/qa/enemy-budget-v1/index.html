# 双标尺敌军标价模型

2026-11-07，标价模型2，已用于v7运行时。本文是公式求值与军费口径；发布必要验证另列，不把预算推导冒充实战。后续新增内容须遵守BALANCE-WORKFLOW.md。

## 两个标尺

- 降智GPT：标价10威胁点，85生命，55移速，7近战伤害/1.1秒，无双抗，漏怪扣1血。
- GLM一级：70建造金币，12物伤/0.6秒，230射程，即20原始DPS。

威胁点是敌军的出兵预算，不是玩家获得的击杀赏金，也不与建造金币直接等额。基准下，一座GLM每持续开火一秒可处理20/85只降智GPT的血量，对应2.3529威胁点。70金币购买的是持续火力，并非只能消灭70点敌军。

新塔方案的GLM二级130金币、34.55 DPS，三级225金币、54 DPS；采用相同标尺换算处理能力。实际还需乘有效开火与覆盖占比，不能把全图所有塔的面板直接相加。

双标尺确定尺度；角色职责、预算分配权重和技能溢价仍须明确选择，不能声称两个标尺足以唯一解出全部属性。以下是首版可调整的设计参数，不是玩家数据拟合结果。

## 先定价格，再分配数值

令H为生命、v为移速、rP/rM为物抗/法抗、d为近战DPS、L为漏怪扣血，S为特殊能力独立预算。

```text
A = 1/(1-rP) × [1 + 0.5×rM/(1-rM)]
E = (H/85) × A
M = log2(1 + d/(7/1.1))

基础战斗预算 C = 10 × [0.75×E^1.15×(v/55) + 0.15×M + 0.10×L]

参考炮弹有效伤害 D = 46 × [0.75×(1-rP) + 0.25×(1-rM)]
若 H <= D：AOE保留系数 K = 1 / [1 + (每排数量-1)/3]
否则 K = 1

价格 P = C×K + S
反解生命：在角色生命上限内，求满足 price(H) <= 标价 的最大H，再向下取整。
```

步骤为：选定标价→确定该角色的抗性、速度、近战和特殊能力模板→解出可负担的生命。生命按5或10取整，未花完的预算单列；不靠取整突破预算。此次调整保持已认可的强单位生命上限，通过提高标价收取集中优势；弱单位降低标价与属性。

75%为存活/抵达预算，15%为近战预算，10%为漏血后果预算；法抗按额外抗性开支折算。等效生命采用1.15次方，使更强单体支付集中优势溢价，不能将一群弱怪的血量压成一个强怪而不加价。近战采用对数，防止溢出伤害被当成数百倍持续收益；精英Grok的一击击倒能力另占20点。

AOE参考跟随新塔模型最高基础等级的大肥鱼，当前为三级46混伤。会被这一炮击杀的mini三列单位，其自身战斗预算按60%保留；同条件普通两列按75%保留；一列不享受群体折价。不会被一炮击杀则不使用该折价。降智GPT85血不会被46伤害一炮击杀，保留10点标尺。折价按受伤与排布条件触发，不是给所有叫“mini”的单位永久打折。此次炮塔修订后，猫仔20HP与Gemini35HP仍符合折价条件，标价维持2/8。

这两个修正解决不同问题：集中溢价体现强单体能持续占用火力，AOE折价体现弱单位一炮清除、伤害共享。技能预算S独立计算，不能将光环和承伤收益再次随自身AOE折价一起减掉。系数1.15与额外列系数1/3是初版策划输入，并非实测定律。

速度增加会缩短防守方的开火窗口，因此提高价格；减速单位在同价下可以获得更多HP。物抗、法抗增加都需要支付预算，不能让高甲单位无偿保留同价血牛的HP。

特殊能力：Gemini保留190范围、80%猫仔加速，预留3.36点（基准6只、2点猫仔、35%生效占比）；脆弱支援的参考生效占比相应下调。Claude保留230范围承伤，预留40点。技能实际价值随编队变化，不能把它们当作精确常数。多只Gemini光环不叠加，出怪权重不得重复奖励重叠光环；超过基准覆盖数量的额外协同单列，不假定8点能无条件代表所有编队。

2026-11-07最新修订：猫仔保持60移速、20生命，低价2点；Gemini保持80移速，改35生命、零双抗、3伤害/1.1秒、漏怪扣1，标价8点。Gemini自身战斗弱于降智GPT，依赖光环支援。

## 波次按钱出兵

每波先给总预算B，再给预算份额q。每类数量约为：

```text
数量 n_i = floor(B×q_i / 单位标价 P_i)
```

随机抽取单位时的权重为`q_i/P_i`归一化，而非直接拿q当数量概率。否则同样的10%权重，昂贵精英会偷偷吃掉远超10%的军费。最低引入数量先占预算，余额再按比例分配；余额不足一只时不透支。

示例：1000点，20%降智GPT、25%中级GPT、55%中级Grok，得到20只降智GPT、10只中级GPT、10只Grok，恰好1000点。将一只55点Grok替换为245点精英Grok，需要额外190点，不能免费替换。

普通波默认精英预算不超过20%，同路精英至少间隔6秒；专门的精英教学波显式例外。mini每排3只、普通2只、精英1只。以上是新规划器规则，不代表现有战斗引擎已经实现新的行军碰撞。

## 关卡难度看预算压力

每波/每关同时输出：总价、出怪跨度、每秒投入、5/10/20秒最高投入、每路投入、重甲/精英/支援占比。总价相同但瞬间投入不同，难度不同；双路总价不能当作单路压力。

GLM基准处理能力为2.3529威胁点/有效开火秒。关卡初步压力可比较“每路滑窗投入”与“当时阵容在该窗口的基准处理能力”，随后考虑范围、控制、克制与有效覆盖。现金只使用当时已到账的金币，四级分支和后续研究必须逐笔扣除。不能用最终累计赏金假定开局买得起。

标价是预算代理量，不能由总价直接推断玩家胜率或地图实际难度。尤其是高物抗、Claude护航、Gemini加速和多路盲区，需要独立标记编队结构。支援预算包含基准溢价，计算编队额外溢价时须先扣除已计入的部分，不能重复加价。
