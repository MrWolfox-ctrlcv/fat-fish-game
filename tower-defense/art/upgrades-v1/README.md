# 升级与造兵图标

ImageGen原创透明5×5图集，共25个独立能力图标。顺序以manifest.json的keys为准：四塔基础升级、六个四级方向、十二项研究/消耗和三种造兵。毒蛋数使用多枚绿毒蛋，毒箭使用淬毒箭，免费蛋使用优惠赠礼券，避免重复通用鸡蛋表情。

保留原扇形面板、卡片坐标、尺寸、名称、价格与操作。仅在原图标槽内显示44像素能力图，紧凑模式36像素；返回、调度、索敌和出售等通用操作保留原符号。每项升级完成后仍显示对应图，不退回箭头或鸡蛋。全套只加载一张640×640透明WebP，解码约1.56MiB，不逐按钮请求图片。

原始PNG保留开发工作区art/upgrades-v1/source.png及ImageGen原输出，不进入发布包。清单记录原稿和运行图集SHA256；转换仅整体等比缩放和WebP编码，没有程序绘制图标。复现：node tools/pack-upgrade-icons-v13.mjs <ImageGen原稿路径>，使用已有sharp，不安装依赖。
