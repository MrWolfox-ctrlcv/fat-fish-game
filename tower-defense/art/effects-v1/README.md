# 毒液地面动画

ImageGen生成：透明背景4列×2行8帧，固定机位、原点和占地，卡通手绘橄榄绿色毒液，气泡鼓起、破裂、涟漪并循环。原稿保留开发工作区；生成工具保存的原文件不删除。运行图集仅做等格拆分、尺寸压缩与WebP编码，无代码绘制的替代美术。清单记录生成原稿SHA256和运行资源SHA256。

运行时以8fps读取同一图集，随战斗暂停；GIF仅供独立预览，不加载到游戏。图集512×256，解码约0.5MiB，不为每个毒区复制图片。以真实毒区半径绘制并在最后0.35秒淡出。转换：node tools/pack-poison-v12.mjs <ImageGen输出路径>，使用已有sharp，不下载素材或依赖。
