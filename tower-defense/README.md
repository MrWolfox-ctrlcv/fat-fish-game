# 肥鱼塔防

2026-11-07，v13升级与造兵配套图标。正式源码仓库为同级fat-fish-game，本目录是塔防开发源；正式运行文件在其tower-defense目录。

自由占地：GLM 2×2，Kimi/Qwen 3×3，大肥鱼4×4。设置选择左侧/底部塔栏，单次落塔后退出建造，只在建造中显示格子；保留原扇形升级面板。入口按钮开波，出怪过半可提前开波获得随剩余时间变化的金币奖励；1/2/3倍速。

八关依次解锁GLM、Kimi、大肥鱼、毒蛋、Qwen、糯米炮、X/鲸鱼巨炮、Qwen量产/巨型分支。过前关开后关，已解锁内容可在旧关使用；简单/普通/困难各一星。四张environment-v4地图分别用于1–2/3–4/5–6/7–8关，图像内已有道路和基地，不重复覆盖旧道路或建筑。

Qwen按单兵付费生产：小模型、普通模型、巨型Qwen；巨型全局只可有一个。双击部队选同类，双击空地后拖动框选，选中后点击地面移动。出售兵营保留已付费部队。召唤古琴按三次拨弦分节：小模型第一节、普通第二节、巨型第三节。

数值必须遵循 [固定策划流程](design/BALANCE-WORKFLOW.md)。[敌军定价](design/ENEMY-PRICE-MODEL.md)、[塔与全部研究定价](design/TOWER-PRICE-MODEL.md)、[单体/对3DPS口径](design/DPS-REFERENCE.md)及两个策略JSON为来源；游戏读取生成的src/freebuild/balance.js。GLM一级和降智GPT为双标尺，威胁点与玩家金币分账。新内容先定价、反解属性、核对角色，再分配波次预算和经济。

重算顺序：`node tools/balance-system/enemy-budget.mjs`、`tower-budget.mjs`、`dps-budget.mjs`、`runtime.mjs`、`campaign.mjs`（后四个同目录）。必要验证：`node qa/release-v12/verify.mjs`。本轮为9组机制检查和8关各12秒运行检查，另有183组波次预算静态审计；没有大规模对战矩阵，也没有宣称所有关卡实测通关。

本地运行 `node server.mjs`，打开 http://127.0.0.1:4190/ 。无需安装新依赖。`tools/build-release.mjs`按白名单同步正式仓库，绝不复制原型、私有运维和真实统计。
