## 玩法与特色

- 11 个成长等级，碰撞、摩擦与角动量带来自然滚动。
- 同级球在一定距离内相互吸附，拉近后滚动接触合成。吸附范围随球大小调整，每只球最多吸附一个最近伙伴，并限制靠拢速度；不同等级、远距离、合成冷却和满级球不受影响。
- 原创生成素材与 20 个固定阶段彩蛋，包括 GPT、伪装 Claude 的 DeepSeek、Astra、豆包和 Gemini。每张造型只对应一个阶段，新增角色分摊原有概率。
- 游客可直接玩；登录账户保存分数与图鉴，未解锁图案保持隐藏。
- 每周排行榜按个人单局最高核验分排名，北京时间周一零点结算，同分先记录者优先。
- 周冠军从独立周奖池获得一张兑换码；缺货保留资格，补货后自动补发，断线或重启不会重复发奖。

鼠标移动选位置，点击投放；触屏或触控笔拖动选位置，松手投放。键盘用 Tab 聚焦鱼缸，再按左右方向键移动，空格或 Enter 投放。音效默认关闭。

## 本地运行

需要 **Node.js 24 或更新版本**（后端使用内置 SQLite）。

```powershell
npm ci --ignore-scripts
npm run prepare:art
Copy-Item .env.example .env
npm start
```

打开 [http://127.0.0.1:4180/games/fat-fish/](http://127.0.0.1:4180/games/fat-fish/)。默认仅监听本机，游戏数据写入 `data/game.sqlite`。本地可直接体验游客玩法；账户、钱包和兑换码管理需要与 New API 部署在同一站点下。

配置示例在 [.env.example](.env.example)。`NEWAPI_URL` 指向已有 New API，`GAME_ORIGINS` 是允许访问游戏 API 的网页来源列表。生产配置由服务管理器注入；不要把 `.env`、数据库、真实兑换码或凭据提交到仓库。

## New API 联动

页面通过同源 `/api/user/auth/refresh` 获取短期账户令牌，仅存于页面内存。后端向已有 New API 验证账户身份与管理员权限，玩家不能自行指定用户 ID、分数或图鉴状态。

游客和账户均由服务器创建随机种子对局。浏览器提交逐步投放记录，后端使用相同物理引擎重新计算分数、解锁和周榜成绩。游戏图片分为当前局许可与账户收藏许可，完整素材图集不由生产服务公开提供。

管理员在「奖品管理」中可以：

1. 新建「合成等级奖励」或「每周榜一奖励」活动。
2. 按名称搜索 New API 已创建且未使用的兑换码，单选或全选导入，每批最多 100 个。
3. 查看活动内库存及领取状态，单个或批量移除尚未领取的码；移除后可重新导入。

等级活动每账户每活动限领一次。周奖只用专用奖池，每周一张，连续获胜可连续获得；不会消耗等级奖品。已领取或已分配的码保留记录，不能移除。导入后的批次应专用于游戏，码的有效期应覆盖结算和兑换时间。

无效活动可在「奖品管理 → 选择活动 → 删除当前活动」中删除。确认框显示活动与兑换码数量；未领取且未分配周奖的码解除游戏奖池分配，已发码与审计记录保留，New API 原码不变。已删除活动不再展示或供新奖励领取，已分配周奖仍归获奖账户所有。清空活动后需要新建活动，不会自动重建被删除的默认活动。

## 资源与可选 AI 陪玩

发布前运行 `npm run prepare:art`，生成私有 `data/art-prepared/`。运行时按需读取独立图片，压缩图片缓存最多 1.5 MiB；生产环境缺缓存会拒绝就绪，不会偷偷在启动时展开全部图集。缓存目录必须随发布包一起部署，不由静态资源路由公开提供。

网页脚本支持 Brotli/gzip 和 ETag 条件请求。角色图片使用私有条件缓存，每次返回图片或 304 之前仍验证当前账户/对局权限；跨局复用图片地址，避免反复下载相同字节。敏感账户与奖品接口不缓存。核验使用一个按需创建的线程，最多排队 4 个请求，空闲 5 秒释放；逐帧算法和防作弊规则保持一致。普通进度合并约 8 秒同步，结束与领奖主动同步。

AI 陪玩默认关闭。配置服务器侧 `.env.example` 中 `COMPANION_*` 后，登录用户可以主动开启简短事件解说与聊天。聊天和事件请求附带有限的实时游戏状态：擂台位置、对手、危险边缘和冲刺状态，或鱼缸最高的 12 条鱼、堆叠高度与危险状态。这是结构化场景读取，不是截图识图，也不持续上传画面；不发送历史聊天、账户名、兑换码或密钥。站内页面不保存聊天记录，模型供应方的数据政策由所选服务决定。

首次遇见的彩蛋阶段、新等级、双杀、连杀、连续落水和长期存活会触发候选解说。每局最多 3 次自动解说，与聊天共用冷却；只保留一个短期有效的优先事件，不补播长队列。事件来自客户端，仅用于旁白，不参与奖励核验。

免费调用默认每账户每日 20 次、全站每日 100 次，北京时间换日；20 秒冷却、最多两路并发、每次最多 192 输出 token，当前 Command Code 通路使用 `reasoning_effort: off`。所有尝试先在 SQLite 中计数，失败也不退次数、不自动重试，重启不会重置限额。次数和 token 上限约束调用规模，实际费用取决于模型供应方计价。AI 只提供旁白和聊天，不控制物理或发放奖励。玩家自带 API Key 的操作型陪玩仍是后续方向，尚未实现。

游戏不创建、删除或使用 New API 原码，也不修改中转站数据库。玩家拿到码后自行前往本站钱包兑换。周奖码仅向获奖账户展示，公共排行榜昵称脱敏。

## 碰碰擂台与联动衣柜

打开 `/games/bumper/` 体验 90 秒击飞积分赛，掉出台外 3 秒复活，当前为一名玩家与五名脚本人机。支持键鼠独立瞄准及触屏双指移动和瞄准。多人房间尚未实现。

点击「衣柜」使用同一个站内账户同步大肥鱼中已解锁的 31 个阶段造型。未解锁只显示问号；服务端验证精确阶段权限，装备结果保存在游戏数据库。默认女仆免费可用，所有造型数值相同。额度购买暂未开放，也没有钱包扣费入口。

两款游戏使用同一套素材接口和最多 1.5 MiB 的服务端图片缓存，不复制第二份图集；衣柜每页最多加载 6 张图并释放离页图片。不同页面各自仍需解码当前图片。AI 陪玩在宽屏显示于游戏右侧，窄屏移到下方，不叠在对战画面上。

擂台发布源代码位于 `playroom/`，由同一个游戏服务提供静态页面。开发时可通过 `node scripts/prepare-playroom.mjs <开发源目录>` 更新白名单文件；发布包不包含开发服务器、凭据或完整图集。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `dist/` | 游戏页面、共享物理引擎、图鉴、周榜及生成素材 |
| `backend/` | 账户校验、操作复算、素材权限、SQLite 奖池和周奖结算 |
| `playroom/` | 碰碰擂台、账户衣柜和场外陪玩界面 |
| `production.mjs` | 独立游戏服务入口 |
| `tests/` | 物理、账户、库存、素材和周奖测试 |
| `deploy/` | 通用独立服务、环境变量与 Nginx 配置示例 |

正式部署把 `/games/fat-fish/` 和 `/games/bumper/` 代理到同一个独立游戏服务，并保留 New API 的账户和钱包路径。游戏独立升级，Nginx 配置检查后平滑加载；不需要停止、重启或替换中转站。示例使用通用路径和演示域名，按实际环境调整即可。
