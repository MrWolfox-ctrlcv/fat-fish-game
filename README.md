## 玩法与特色

- 11 个成长等级，碰撞、摩擦与角动量带来自然滚动。
- 同级球在一定距离内相互吸附，拉近后滚动接触合成。吸附范围随球大小调整，每只球最多吸附一个最近伙伴，并限制靠拢速度；不同等级、远距离、合成冷却和满级球不受影响。
- 原创生成素材与 20 个固定阶段彩蛋，包括 GPT、伪装 Claude 的 DeepSeek、Astra、豆包和 Gemini。每张造型只对应一个阶段，新增角色分摊原有概率。
- 游客可直接玩；登录账户保存分数与图鉴，未解锁图案保持隐藏。
- 每周排行榜按个人单局最高核验分排名，北京时间周一零点结算，同分先记录者优先。
- 周冠军从独立周奖池获得一张兑换码；缺货保留资格，补货后自动补发，断线或重启不会重复发奖。

鼠标移动选位置，点击投放；触屏或触控笔拖动选位置，松手投放。键盘用 Tab 聚焦鱼缸，再按左右方向键移动，空格或 Enter 投放。音效默认关闭。

## 本地运行

需要 **Node.js 24 或更新版本**（后端使用内置 SQLite）。

```powershell
npm ci --ignore-scripts
Copy-Item .env.example .env
npm start
```

打开 [http://127.0.0.1:4180/games/fat-fish/](http://127.0.0.1:4180/games/fat-fish/)。默认仅监听本机，游戏数据写入 `data/game.sqlite`。本地可直接体验游客玩法；账户、钱包和兑换码管理需要与 New API 部署在同一站点下。

配置示例在 [.env.example](.env.example)。`NEWAPI_URL` 指向已有 New API，`GAME_ORIGINS` 是允许访问游戏 API 的网页来源列表。生产配置由服务管理器注入；不要把 `.env`、数据库、真实兑换码或凭据提交到仓库。

## New API 联动

页面通过同源 `/api/user/auth/refresh` 获取短期账户令牌，仅存于页面内存。后端向已有 New API 验证账户身份与管理员权限，玩家不能自行指定用户 ID、分数或图鉴状态。

游客和账户均由服务器创建随机种子对局。浏览器提交逐步投放记录，后端使用相同物理引擎重新计算分数、解锁和周榜成绩。游戏图片分为当前局许可与账户收藏许可，完整素材图集不由生产服务公开提供。

管理员在「奖品管理」中可以：

1. 新建「合成等级奖励」或「每周榜一奖励」活动。
2. 按名称搜索 New API 已创建且未使用的兑换码，单选或全选导入，每批最多 100 个。
3. 查看活动内库存及领取状态，单个或批量移除尚未领取的码；移除后可重新导入。

等级活动每账户每活动限领一次。周奖只用专用奖池，每周一张，连续获胜可连续获得；不会消耗等级奖品。已领取或已分配的码保留记录，不能移除。导入后的批次应专用于游戏，码的有效期应覆盖结算和兑换时间。

游戏不创建、删除或使用 New API 原码，也不修改中转站数据库。玩家拿到码后自行前往本站钱包兑换。周奖码仅向获奖账户展示，公共排行榜昵称脱敏。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `dist/` | 游戏页面、共享物理引擎、图鉴、周榜及生成素材 |
| `backend/` | 账户校验、操作复算、素材权限、SQLite 奖池和周奖结算 |
| `production.mjs` | 独立游戏服务入口 |
| `tests/` | 物理、账户、库存、素材和周奖测试 |
| `deploy/` | 通用独立服务、环境变量与 Nginx 配置示例 |

正式部署把 `/games/fat-fish/` 代理到独立游戏服务，并保留 New API 的账户和钱包路径。游戏独立升级，Nginx 配置检查后平滑加载；不需要停止、重启或替换中转站。示例使用通用路径和演示域名，按实际环境调整即可。
